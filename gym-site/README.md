# IRON CULT FITNESS

Premium modern gym & fitness marketing site.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Run locally

```bash
cd gym-site
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
cd gym-site
npm run build
npm start
```

## Edit gym details

All brand, contact, address, prices, trainers, programs, and social links live in one file:

**`src/config/gym.ts`**
