# Aether Athletics

Luxury gym marketing site — React + Vite landing page.

## Run locally

```bash
cd gym-site
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
cd gym-site
npm run build
npm run preview
```

## Sections

- **Hero** — full-bleed brand-first composition
- **Memberships** — Atelier / Private / Residence tiers
- **Amenities** — strength, recovery, studios, lounge
- **Contact** — inquiry form (client-side only in v1)
